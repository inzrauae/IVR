# MASTER DEVELOPMENT PROMPT — CLOUD PBX SAAS PLATFORM

## 1. Project Overview

Act as a senior Laravel architect, VoIP engineer, UI/UX designer, DevOps engineer, and full-stack SaaS developer.

Build a complete, production-oriented, multi-tenant Cloud PBX management platform inspired by the capabilities of 3CX, FreePBX, and modern business communication systems.

The application must use **Laravel as the main backend and administrative framework**, with an open-source PBX engine for telephony.

Create an original, premium interface rather than copying any existing vendor's proprietary dashboard or branding.

The system must support multiple organizations, each with independent users, extensions, phone numbers, call flows, queues, recordings, reports, billing, and integrations.

This must be a working application, not just a UI prototype.

## 2. Technology Stack

Use:

- Backend: Laravel 12 or latest compatible stable version
- PHP: 8.3+
- Frontend: Vue 3, TypeScript, Inertia.js
- Styling: Tailwind CSS
- UI components: shadcn-vue or equivalent
- Database: PostgreSQL
- Cache and queues: Redis
- Realtime: Laravel Reverb and Laravel Echo
- Authentication: Laravel Fortify or equivalent
- Authorization: Laravel Policies and Spatie Laravel Permission
- API authentication: Laravel Sanctum
- PBX engine: Asterisk with PJSIP
- PBX management: Asterisk ARI, AMI, and controlled configuration provisioning
- Optional PBX distribution: FreePBX, integrated through supported interfaces
- WebRTC: SIP.js
- SIP transport: TLS and WSS
- Media: RTP/SRTP
- Deployment: Ubuntu Linux, Nginx, Supervisor, systemd
- Monitoring: Prometheus/Grafana-compatible metrics
- Testing: Pest/PHPUnit, Vitest, Playwright

Important: Asterisk should be the default telephony engine. FreePBX integration should be optional because its configuration ownership and dialplan management require special handling. Never write directly to FreePBX-managed configuration or databases without a supported integration strategy.
